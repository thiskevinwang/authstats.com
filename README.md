## App

This repo contains a Next.js app deployed to Cloudflare Workers through OpenNext. The UI reads package download and version snapshots from D1; registry-derived stats are written asynchronously by the ingestion workflow before the app can display them.

```bash
bun install
bun run db:migrate:local
bun run dev
```

For production, create the D1 database, replace the placeholder `database_id` in `wrangler.jsonc`, apply migrations remotely, and deploy:

```bash
bun run db:create
bun run db:migrate:remote
bun run deploy
```

The Worker exports `DownloadStatsWorkflow` and has a cron trigger configured for every six hours. The same workflow can be started manually in production with `POST /api/etl/run`.
